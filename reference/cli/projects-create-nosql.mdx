# forest projects:create:nosql

Create a new Forest Admin project.

## Usage

```bash
forest projects:create:nosql [APPLICATIONNAME] [options]
```

## Arguments

| Argument | Description |
|---|---|
| `APPLICATIONNAME` | Name of the project to create. |

## Options

| Option | Description |
|---|---|
| `-H, --applicationHost=<value>` | Hostname of your admin backend application. |
| `-P, --applicationPort=<value>` | Port of your admin backend application. |
| `-c, --databaseConnectionURL=<value>` | Enter the database credentials with a connection URL. |
| `-h, --databaseHost=<value>` | Enter your database host. |
| `-l, --language=<option>` | Choose the language you want to use for your project. <options: javascript\|typescript> |
| `-n, --databaseName=<value>` | Enter your database name. |
| `-p, --databasePort=<value>` | Enter your database port. |
| `-u, --databaseUser=<value>` | Enter your database user. |
| `--databasePassword=<value>` | Enter your database password. |
| `--databaseSSL` | Use SSL for database connection. |
| `--databaseSslMode=<option>` | SSL mode. <options: preferred\|verify\|required\|disabled> |
| `--mongoDBSRV` | Use SRV DNS record for mongoDB connection. |
