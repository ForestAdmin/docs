# forest environments:delete

Delete an environment.

## Usage

```bash
forest environments:delete [ENVIRONMENTID] [options]
```

## Arguments

| Argument | Description |
|---|---|
| `ENVIRONMENTID` | ID of an environment. |

## Options

| Option | Description |
|---|---|
| `-f, --force` | Force delete. |
