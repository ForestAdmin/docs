# Layout

Manage your UI layout as code — pull it to a file, apply it, or patch it directly.

## forest layout:pull

Pull the layout (rendering) of an environment into a forest-layout.json file.

```bash
forest layout:pull [options]
```

| Option | Description |
|---|---|
| `-e, --env=<value>` | Environment to pull from (name or id). Defaults to the environment of FOREST_ENV_SECRET when set, otherwise the development environment. |
| `-o, --out=<value>` | [default: forest-layout.json] Output file path (default: forest-layout.json). |
| `-p, --projectId=<value>` | Id of the project (resolved automatically when you only have one). |
| `-t, --team=<value>` | Team whose layout to pull (name or id). Defaults to the "Operations" team. |
| `--with-workflows` | Also download each workflow's BPMN into sidecar files (workflows/<id>.bpmn) for round-trip. |

## forest layout:apply

Apply a forest-layout.json to an environment (pushes JSON-Patch changes).

```bash
forest layout:apply [FILE] [options]
```

| Argument | Description |
|---|---|
| `FILE` | Layout file to apply (e.g. forest-layout.json). |

| Option | Description |
|---|---|
| `-e, --env=<value>` | Environment to apply to (name or id). Prompted if omitted. |
| `-f, --force` | Skip the confirmation prompt. |
| `-p, --projectId=<value>` | Id of the project (resolved/prompted when omitted). |
| `-t, --team=<value>` | Team to apply to (name or id). Prompted if omitted. |
| `--with-workflows` | Also upload workflow BPMN sidecars (workflows/<id>.bpmn) to the target env — the round-trip counterpart of `pull --with-workflows`. |

## forest layout:patch

Patch the layout directly (single PATCH per domain, like the front — no pull/apply).

```bash
forest layout:patch [FILE] [options]
```

| Argument | Description |
|---|---|
| `FILE` | JSON patch file to apply. Use "-" or omit to read from stdin. |

| Option | Description |
|---|---|
| `-e, --env=<value>` | Environment name or id. |
| `-f, --force` | Skip the confirmation prompt (required when reading from stdin). |
| `-p, --projectId=<value>` | Project id. |
| `-t, --team=<value>` | Team name or id. |
| `--dry-run` | Print operations without sending them. |
