# forest users:list

List all users of a project.

## Usage

```bash
forest users:list [options]
```

## Options

| Option | Description |
|---|---|
| `-f, --format=<option>` | [default: table] Output format. <options: table\|json> |
| `-p, --projectId=<value>` | Forest project ID. |
