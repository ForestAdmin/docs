# forest layout:pull

Pull the layout (rendering) of an environment into a forest-layout.json file.

## Usage

```bash
forest layout:pull [options]
```

## Options

| Option | Description |
|---|---|
| `-e, --env=<value>` | Environment to pull from (name or id). Defaults to the environment of FOREST_ENV_SECRET when set, otherwise the development environment. |
| `-o, --out=<value>` | [default: forest-layout.json] Output file path (default: forest-layout.json). |
| `-p, --projectId=<value>` | Id of the project (resolved automatically when you only have one). |
| `-t, --team=<value>` | Team whose layout to pull (name or id). Defaults to the "Operations" team. |
| `--with-workflows` | Also download each workflow's BPMN into sidecar files (workflows/<id>.bpmn) for round-trip. |
