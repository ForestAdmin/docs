# forest roles:create

Create a new role in a project.

## Usage

```bash
forest roles:create [options]
```

## Options

| Option | Description |
|---|---|
| `-n, --name=<value>` | (required) Name of the role to create. |
| `-p, --projectId=<value>` | Forest project ID. |
