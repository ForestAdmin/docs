# forest teams:create

Create a new team in a project.

## Usage

```bash
forest teams:create [options]
```

## Options

| Option | Description |
|---|---|
| `-n, --name=<value>` | (required) Name of the team to create. |
| `-p, --projectId=<value>` | Forest project ID. |
