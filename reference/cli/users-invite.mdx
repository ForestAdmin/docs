# forest users:invite

Invite users to a project.

## Usage

```bash
forest users:invite [options]
```

## Options

| Option | Description |
|---|---|
| `-e, --email=<value>...` | (required) Email of the user to invite (repeat the flag to invite several users). |
| `-f, --format=<option>` | [default: table] Output format. <options: table\|json> |
| `-l, --permission-level=<option>` | (required) Permission level of the invited users. <options: admin\|editor\|user\|developer\|manager> |
| `-p, --projectId=<value>` | Forest project ID. |
| `-r, --role=<value>` | Role name to assign (prompted if omitted and several exist). |
| `-t, --team=<value>` | Team name to add the invited users to (prompted if omitted and several exist). |
