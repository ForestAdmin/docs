# Users

List, invite, and edit the users of a project.

## forest users:list

List all users of a project.

```bash
forest users:list [options]
```

| Option | Description |
|---|---|
| `-f, --format=<option>` | [default: table] Output format. <options: table\|json> |
| `-p, --projectId=<value>` | Forest project ID. |

## forest users:invite

Invite users to a project.

```bash
forest users:invite [options]
```

| Option | Description |
|---|---|
| `-e, --email=<value>...` | (required) Email of the user to invite (repeat the flag to invite several users). |
| `-f, --format=<option>` | [default: table] Output format. <options: table\|json> |
| `-l, --permission-level=<option>` | (required) Permission level of the invited users. <options: admin\|editor\|user\|developer\|manager> |
| `-p, --projectId=<value>` | Forest project ID. |
| `-r, --role=<value>` | Role name to assign (prompted if omitted and several exist). |
| `-t, --team=<value>` | Team name to add the invited users to (prompted if omitted and several exist). |

## forest users:edit

Edit a user's role, team(s) or permission level.

```bash
forest users:edit [options]
```

| Option | Description |
|---|---|
| `-e, --email=<value>` | (required) Email of the user to edit. |
| `-f, --force` | Skip the confirmation prompt when teams would be removed. |
| `-l, --permission-level=<option>` | New permission level. <options: admin\|editor\|user\|developer\|manager> |
| `-p, --projectId=<value>` | Forest project ID. |
| `-r, --role=<value>` | New role name to assign. |
| `-t, --team=<value>...` | Team name to set for this project. Repeatable; this REPLACES the user’s current team set on the project. |
