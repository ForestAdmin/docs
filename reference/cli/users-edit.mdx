# forest users:edit

Edit a user's role, team(s) or permission level.

## Usage

```bash
forest users:edit [options]
```

## Options

| Option | Description |
|---|---|
| `-e, --email=<value>` | (required) Email of the user to edit. |
| `-f, --force` | Skip the confirmation prompt when teams would be removed. |
| `-l, --permission-level=<option>` | New permission level. <options: admin\|editor\|user\|developer\|manager> |
| `-p, --projectId=<value>` | Forest project ID. |
| `-r, --role=<value>` | New role name to assign. |
| `-t, --team=<value>...` | Team name to set for this project. Repeatable; this REPLACES the user’s current team set on the project. |
